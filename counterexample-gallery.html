Counterexample Gallery

This page shows what breaks when a correct-looking sentence drops a needed condition. Each card starts with a tempting claim, names the missing condition, gives a concrete failure scene, and repairs the sentence.

How To Use A Counterexample

Do not read a counterexample as a separate topic. Read it as a stress test for a claim you wanted to believe. If the claim fails after one condition is removed, that condition belongs in the explanation. The point is not to memorize the failure scene; the point is to learn which permission the original argument needed.

The repair line matters because a counterexample should not leave the reader with only a warning. It should teach how to write the sentence correctly: name the object, name the condition, and state the conclusion that remains justified.

Failure scene

Flattening a twist loses the surface

Tempting claim: The strip can be flattened into an ordinary band, so the two strip pictures should answer the same question.

Missing condition: The flattening forgot the end-gluing rule. A legal simplification must preserve which edge points are identified and how a route returns after one trip.

Failure scene: A local drawing of a twisted strip and an untwisted band may look like the same rectangle, but walking around the finished strip records different side information.

Why it breaks: The simplified picture changed the whole object. It did not merely move the object; it replaced the gluing rule that carries the global fact.

Repair: State the gluing rule before drawing. Then any simplification has to preserve that rule, not only the visible rectangular shape.

Failure scene

Moving an endpoint removes the obstruction

Tempting claim: Two routes can be uncrossed by sliding one endpoint around the boundary, so the crossing was never forced.

Missing condition: The boundary data are part of the problem. Endpoint order, marked points, or boundary labels must stay fixed during the deformation.

Failure scene: If an endpoint can move freely around the boundary, a route obstruction may vanish, but that motion answers a different route problem.

Why it breaks: The argument changed the rulebook at the boundary. The original obstruction lived in the boundary order that was silently rearranged.

Repair: Mark the endpoints and keep them fixed while simplifying the interior. Then test whether a crossing remains forced under that restricted motion.

Failure scene

Counting raw crossings overreads the picture

Tempting claim: The drawing has two crossings, so the mathematical evidence should be the visible number two.

Missing condition: The count needs a survival rule. Raw crossings can appear or disappear under legal motion unless signs, parity, or another protected account is being used.

Failure scene: A small legal nudge can create a pair of crossings or remove a pair without changing the problem being studied.

Why it breaks: The raw number measured an accident of the drawing. It did not name the part of the count that survives the allowed changes.

Repair: Ask what the legal moves do to the count. Use signed totals, parity, or another protected account only after explaining why it survives.

Failure scene

Using signs without orientation

Tempting claim: The plus crossings and minus crossings cancel, so the signed total proves the same conclusion.

Missing condition: The signs need a shared direction rule. Orientation or boundary orientation must make plus and minus comparable across the object.

Failure scene: If each local sign is chosen independently, the symbols may cancel on paper while failing to describe one consistent mathematical account.

Why it breaks: The addition used labels that did not belong to the same rulebook. A signed total has meaning only when the sign convention can be carried consistently.

Repair: Name the orientation source first. If the object cannot support the required direction rule, do not use signed cancellation as evidence.

Failure scene

Applying Brouwer outside its contract

Tempting claim: A continuous rule has a fixed point because Brouwer says continuous maps have fixed points.

Missing condition: The rule must map the right kind of space back into itself and satisfy the theorem's setup. The domain, target, boundary, and continuity conditions matter.

Failure scene: A rule from an interval into a larger line can move every point outside the interval, so the diagonal comparison inside the original interval no longer applies.

Why it breaks: The theorem was asked to speak about the wrong object. Self-agreement is a statement inside one space, not a reward for any continuous formula.

Repair: Before naming Brouwer, name the space, the rule, where outputs land, and which condition forces the graph to meet the diagonal.

Failure scene

Leaving out one vector-field defect

Tempting claim: The visible equilibria have total index zero, so the surface allows a defect-free field elsewhere.

Missing condition: Every isolated defect on the relevant surface must be counted, and the field must satisfy the theorem's surface or boundary conditions.

Failure scene: A drawing can hide a defect outside the pictured patch or at the boundary, making the visible total smaller than the true whole-surface account.

Why it breaks: Poincare-Hopf compares the complete local total with the whole surface. A partial list is not the theorem's local side.

Repair: Name the surface, inspect all defects, state boundary behavior, and only then compare the total index with Euler characteristic.

Failure scene

Modeling motion with missing forbidden states

Tempting claim: A path exists in the drawn state diagram, so the physical system can move that way.

Missing condition: The configuration space must remove every forbidden state and record every freedom needed to describe one complete physical state.

Failure scene: If collision states remain in the diagram, a path may pass through a physical impossibility while looking continuous in the model.

Why it breaks: The topology was applied to the wrong state space. Paths in the model no longer correspond to legal motions of the original system.

Repair: Say what one point records, remove forbidden states, then ask whether a path through the remaining space represents a real motion.

Failure scene

Changing the surface during a cell count

Tempting claim: The Euler characteristic changed after redrawing the cells, so the surface number itself changed.

Missing condition: Both cell accounts must describe the same surface. Refining or redrawing cells is allowed; changing the gluing, boundary, or surface type is not.

Failure scene: A careless diagram can drop a boundary edge or double-count a glued edge, producing a new number that belongs to the bookkeeping error.

Why it breaks: The alternating count only survives valid changes in the cell account. It does not protect mistakes that change the surface being counted.

Repair: Check the surface first, then check vertices, edges, and faces. The count is evidence only when the cell account still describes the same object.

Failure scene

Reading a source as stronger than it is

Tempting claim: The reference is listed, so it proves the exact sentence on the lecture page.

Missing condition: A source supports only the claim its evidence can actually carry: course identity, background family, formal theorem, visible lecture move, or recovered caption wording.

Failure scene: A background text may support vector-field index as a mathematical family without proving that Tokieda stated one exact sentence in one lecture.

Why it breaks: The citation was used as authority without naming the claim it supports. That turns a source trail into overclaiming.

Repair: Name the sentence, name the source evidence, and weaken the sentence if the evidence supports only a background family or course-arc inference.

Failure scene

Treating a theorem as a procedure

Tempting claim: The theorem proves existence, so it also tells us how to find the object or path.

Missing condition: The theorem's conclusion must be read exactly. Some results force existence, parity, obstruction, or total count without giving a construction or location.

Failure scene: A fixed-point theorem may prove that some point exists while giving no recipe for finding it, and Poincare-Hopf may constrain defects without solving trajectories.

Why it breaks: The answer asked the theorem for more than its contract provides. Existence, location, construction, and computation are different kinds of conclusions.

Repair: State the conclusion type: existence, obstruction, equality, parity, or count. Then say what stronger conclusion remains unproved.

The Counterexample Test

Use this page after the assumption ledger. The assumption ledger asks what must be true. The counterexample gallery asks what goes wrong when it is not true. Together they make theorem use and modeling accountable.

A good counterexample answer has three sentences. First, it says the tempting claim in plain language. Second, it says which condition was removed. Third, it explains why the repaired claim is weaker but now true for the original course object.

Repairing A Failed Claim

When a counterexample breaks a sentence, do not replace it with a vague warning. Repair the sentence by naming the condition that was missing. If the problem changed at the boundary, say the boundary data must stay fixed. If a count failed, say which part of the count survives legal moves. If a model failed, say what one state records and which states are forbidden.

The repair should be smaller than a new explanation. A useful repair often begins with words like provided that, as long as, after checking, or for this same object. Those words are not decoration. They are the permission that lets the claim speak.

Use the repaired sentence on the matching lecture, concept, theorem contract, or source page. A reader should be able to return to the original explanation and see exactly where the missing condition now belongs.

How To Review With This Gallery

Pick a page and find its strongest claim. Then ask which card in this gallery could break that claim if a condition were removed. A deformation page should survive the endpoint and gluing tests. A counting page should survive the raw-count and sign-rule tests. A fixed-point page should survive the same-space test. A source page should survive the exact-claim test.

The point is not to make every page longer. The point is to prevent a short sentence from hiding a changed problem. If the condition is already visible nearby, leave the page alone. If it is missing, add one plain sentence before the theorem name, count, model, or citation is used.

Connection To Readiness

Use this gallery before the oral exam. For each oral answer, ask for one failure scene. If the answer explains deformation, ask what illegal move would make the deformation false. If it explains a theorem, ask which assumption would make the theorem stop applying. If it explains a source, ask which stronger sentence would overread the evidence.

This is how the companion avoids shallow confidence. A reader is not ready when they can only state the correct version. They are ready when they can also say what nearby false version would fail and how to repair it.

During review, give credit only when the failure scene changes one named condition and leaves the rest of the problem recognizable. If everything changes at once, the counterexample is too vague to teach the original claim.

The best failure scene is small, local, and easy to inspect.
