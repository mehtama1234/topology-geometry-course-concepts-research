Proof Moves

These are the reusable moves beneath the lectures. Each recipe starts from the everyday problem, names the legal contract, explains why the move works, and names the failure that would make the proof invalid.

How To Use These Recipes

When a page feels compressed, find the proof move it is using. Do not start with the theorem name. Start with the action: move a picture, build a count, translate a rule, add local defects, or model possible states. Then ask what detail makes the action legal.

The course becomes easier when every proof is read as a sequence of obligations. What is the object? What may change? What must survive? What count or comparison is protected? What conclusion follows because the protected evidence cannot be removed?

Deform a picture without changing the original question

The first drawing is too tangled to reason from directly.

Steps:

  1. Name the object that is allowed to move.
  2. Name the forbidden moves: passing through, breaking, gluing, moving endpoints, or dropping a boundary.
  3. Move the picture only through legal changes.
  4. State the fact that survived the whole motion.
  5. Use the simpler final picture to answer the original question.

Why it works: The proof works because each legal step preserves the question. The final picture is useful only because the journey to it was honest.

Failure mode: The usual failure is simplifying first and justifying later. If the legal moves are not named before the motion, the proof may have solved a different problem.

Course example: The disk path puzzle uses deformation to show that endpoint order and no-crossing rules can force an obstruction.

Family: deformation-family

Build a count that survives legal redrawings by cancellation

The visible number of pieces, crossings, or defects changes when the picture is cleaned up.

Steps:

  1. Decide which local events matter.
  2. Watch how those events can appear or disappear under legal motion.
  3. Choose an account where harmless changes cancel.
  4. Check the account on a simple version of the object.
  5. Use the protected total to force existence or impossibility.

Why it works: A useful count is designed around its allowed changes. Euler characteristic, parity, intersection number, and index all work because fake changes do not alter the protected account.

Failure mode: The raw count is often the wrong count. If the proof does not explain why the number survives, the number is only a measurement of one drawing.

Course example: Signed intersection number counts plus and minus meetings so pairs born during deformation add to zero.

Family: counting-family

Translate an invisible rule into a comparable shape

A map or motion law feels invisible because it is an instruction rather than a drawn object.

Steps:

  1. List the input space and output space.
  2. Draw or describe the graph that records input and output together.
  3. Identify the comparison object, such as the diagonal of self-agreement.
  4. Turn the desired conclusion into a meeting or avoidance question.
  5. Apply the earlier count, obstruction, or fixed-point idea.

Why it works: The proof works because the rule becomes an object that can be moved, compared, and counted. A fixed point is no longer hidden inside notation; it is a meeting with the diagonal.

Failure mode: The translation fails if the graph no longer represents the original rule or if the diagonal does not represent the desired self-agreement.

Course example: Fixed-point lectures turn f(x) = x into the graph of f meeting the diagonal.

Family: motion-family

Read local defects as evidence about the whole surface

A vector field may have several local failures, and each one looks adjustable in isolation.

Steps:

  1. Clean the field so the defects are isolated.
  2. Walk around each defect with a small loop.
  3. Record how the nearby arrows turn.
  4. Add the signed local indices.
  5. Compare the total with the surface's Euler characteristic.

Why it works: The proof works because isolated local defects can move or cancel in controlled ways, but their total is tied to the surface that carries the field.

Failure mode: The theorem is misread when one equilibrium is treated as the whole story. Poincare-Hopf is about the total over the complete surface.

Course example: The hairy-ball idea is the plain case: a sphere cannot carry a continuous nonzero tangent arrow field everywhere.

Family: surface-family

Model physical motion as a space of possible states

A physical setup has too many details to track directly over time.

Steps:

  1. Say what information describes one complete state.
  2. Treat every possible state as a point in a new space.
  3. Remove forbidden states or mark boundary restrictions.
  4. Translate motion into paths or rules on that state space.
  5. Use holes, barriers, fixed points, or indices to constrain the original system.

Why it works: The proof works only if the state space carries the real freedoms and real exclusions of the physical problem. Topology then reasons about the shape of possibility.

Failure mode: A careless state space can prove a true theorem about the wrong model. The physical conclusion is only as good as the translation.

Course example: The late applications use state spaces and protected obstructions to reason about motion without solving every trajectory.

Family: motion-family

Audit Question

After reading any proof in the course, ask which recipe was used and where the proof paid its debt. A deformation proof pays its debt by naming legal motion. A counting proof pays its debt by explaining cancellation. A fixed-point proof pays its debt by translating the rule into a graph-and-diagonal meeting. A dynamics proof pays its debt by showing why local defects can be added over the whole surface.
